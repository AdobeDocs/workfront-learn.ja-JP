# Workfrontでタスクを効果的に順序付け – SHARED

ビデオでは、先行タスクと期間を使用して Workfront でタスクを順序付け、プロジェクトのタイムラインを効果的に管理する方法について説明します。
このビデオでは、新しいタスクの先行タスクを設定し、順序付けと正確な開始日を確保する方法を説明します。
&#x200B;先行者と協力してプロジェクトのタイムラインへの影響を把握する重要性を強調し、効率的なプロジェクト計画のために期間と先行者を使用することを推奨しています。


>[!VIDEO](https://video.tv.adobe.com/v/335091/?quality=12&learn=on&enablevpops=1)

## 重要な留意点

* **先行者タスク順序の定義：**&#x200B;先行者は、タスクの順序を確立し、特定のタスクが完了してから他のタスクが開始できるようにします。これは、プロジェクトの成功にとって非常に重要です。 &#x200B;
* **期間の影響タイムライン：** タスク期間は、作業の時間枠を設定し、開始日と完了日を調整して、依存タスクにカスケーディング効果を生み出します。 &#x200B;
* **テンプレート セットアップの簡素化：**&#x200B;先行タスクと制約は、プロジェクトテンプレートで事前に設定できるため、タスクシーケンスを管理するプロセスを合理化できます。 &#x200B;
* **手動による調整が制約に影響：**&#x200B;特定の日付を手動で設定すると、期間または先行タスクの変更によるカスケーディング更新が上書きされます。 &#x200B;
* **プラクティスによるスキルの向上：**&#x200B;先行タスクや期間に関するプラクティスは、プロジェクト管理スキルを洗練させ、タイムラインをより適切に管理するのに役立ちます。
